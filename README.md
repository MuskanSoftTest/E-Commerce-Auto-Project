# 🛒 E-Commerce Automation Project

This is an **automation testing project for an e-commerce web application** using **Java, Selenium WebDriver, TestNG, and GitHub Actions CI**.

---

## 🚀 **Project Overview**

✅ Automates UI test cases for e-commerce features  
✅ Uses **Page Object Model (POM)** design pattern  
✅ Integrates with **GitHub Actions** for continuous integration  
✅ Generates **Allure Reports** for professional reporting

---

## 🔧 **Tech Stack**

- **Programming Language:** Java
- **Automation Tool:** Selenium WebDriver
- **Testing Framework:** TestNG
- **Build Tool:** Maven
- **Reporting:** Allure Reports
- **CI/CD:** GitHub Actions

## ⚙️ **How to Run Tests**

1. **Clone the repository**

```bash
git clone https://github.com/MuskanSoftTest/E-Commerce-Auto-Project.git
cd E-Commerce-Auto-Project

**Install dependencies**

Ensure JDK 17, Maven, and Chrome browser are installed on your system.

**Run tests**
mvn clean test

**Generate Allure Report**
mvn allure:report
mvn allure:serve
